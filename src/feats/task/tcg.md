### 简介

支持角色邀请、每周来客挑战、部分大世界NPC挑战。

部分场景不支持、或是打不过、拿不满奖励。

支持角色被超载、冻结等异常情况。

**不支持或胜率低的场景：**

- 雷电将军相关卡组由于无充能判断，可能在被冻结后无法进行后续步骤
- 雷电将军相关卡组中，雷电将军在未开大被击杀时，无法胜利且策略执行会出现问题
- 角色被超载击败，会无法判断角色是否被击败
- 某些场地牌存在情况下，胜率较低

### 使用指南

1、首先在七圣召唤任务配置中选择合适的卡组，角色牌顺序一定要按照卡组名称的顺序，**带什么牌无所谓**。推荐使用 `雷神柯莱刻晴` 卡组，胜率高，普适强，速度快，T3结束对局（感谢群友`@我欲乘风`的制作与分享）。自定义策略可以看下方“自定义打牌策略”的说明。

> 注意：卡组不能无脑选，需要根据不同的场景选择，比如出现大量史莱姆的对局，使用 `莫娜砂糖琴` 卡组会更好。

![选择合适的牌组](https://img.alicdn.com/imgextra/i3/2042484851/O1CN01Be1OsT1lhoEhEtfAB_!!2042484851.png)

2、 **目前仅支持 `1920x1080` 分辨率的游戏，其他 `16:9` 分辨率会存在内容识别问题**

3、在游戏内进入七圣召唤对局，点击**初始手牌**界面（如下图）

![](https://img.alicdn.com/imgextra/i3/2042484851/O1CN01OR8onj1lhoDuK1JXB_!!2042484851.jpg)

4、点击“开始”进行自动打牌，双手离开键盘鼠标。

### 自定义打牌策略

在软件当前目录的 `User\AutoGeniusInvokation` 下放置 `UTF-8` 编码的 `.txt` 文件。界面里显示的策略名就是**文件名**（不含扩展名）。建议先复制内置示例再改，例如 `8.雷神柯莱刻晴[推荐].txt`。

::: warning 这不是条件脚本

自定义策略是一份从上到下执行的**指令列表**。骰子**数量**不够时，结束本回合；下回合接着做还没做完的指令，不会从文件第一行重来。

**不能**写成「手里有某张牌就打出」「对方是史莱姆就换打法」「充能满了再放大」。程序不识别牌名，手牌都是拿来烧的。

:::

#### 文件结构

文件分两段即可，靠 `角色定义:` 和 `策略定义:` 区分。中间的 `---` 可写可不写。标题必须用英文冒号 `:`，不要用中文 `：`。

```txt
角色定义:
角色1=雷神
角色2=柯莱
角色3=刻晴
---
策略定义:
雷神 使用 技能3
雷神 使用 技能2
雷神 使用 技能1
柯莱 使用 技能1
刻晴 使用 技能2
刻晴 使用 技能1
```

| 写法                      | 作用                                                               |
| ------------------------- | ------------------------------------------------------------------ |
| `角色定义:` / `策略定义:` | 段落标题，必须原样书写                                             |
| `---`                     | 可写可不写，解析时跳过                                             |
| `// 注释`                 | 整行忽略。**不要在注释里写英文冒号 `:`**，否则会被当成新的段落标题 |
| 空行、多余空格            | 忽略                                                               |

文件不是 UTF-8 时，常见报错是「角色未定义，请确认策略文本格式是否为UTF-8」。

#### 角色定义

必须写满 `角色1`、`角色2`、`角色3`。`角色1` 是游戏里最左边的角色，`角色3` 是最右边。

##### 简写（0.23 之后推荐）

卡牌表里有的角色，只写名字即可，技能费用会自动套默认配置：

```txt
角色定义:
角色1=芙宁娜
角色2=卡维
角色3=吞星之鲸
```

能写哪些名字，到软件安装目录里打开这两份文件看（用记事本搜中文名即可）：

| 用途       | 本地路径                                                       | 在线                                                                                                                                                |
| ---------- | -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 卡牌正式名 | `GameTask\AutoGeniusInvokation\Assets\tcg_character_card.json` | [查看](https://github.com/babalae/better-genshin-impact/blob/main/BetterGenshinImpact/GameTask/AutoGeniusInvokation/Assets/tcg_character_card.json) |
| 战斗别名   | `GameTask\AutoFight\Assets\combat_avatar.json`                 | [查看](https://github.com/babalae/better-genshin-impact/blob/main/BetterGenshinImpact/GameTask/AutoFight/Assets/combat_avatar.json)                 |

- 卡牌表：搜角色中文名，条目里的 `"name"` 就是可直接写的正式名，例如 `甘雨`、`菲谢尔`、`丘丘岩盔王`。
- 别名表：搜你想用的称呼，看它落在哪个角色的 `"alias"` 里。`雷神`、`皇女`、`科莱` 都可以用来套默认费用。

程序先按你写的名字去卡牌表精确匹配；找不到再按战斗别名换成正式名，再去卡牌表取费用。**指令里的角色名必须和角色定义里写的完全一致**：定义成 `雷神`，后面就要写 `雷神 使用 技能2`。

简写匹配不到时会报错，请改用下面的完整写法。怪物牌一般没有战斗别名，简写必须用卡牌表里的正式名；示例里的 `丘丘王` 能用，是因为走了完整定义。

##### 完整写法

自行指定元素和每个技能的骰子消耗。单行格式：`角色N=名字|元素{技能K消耗=...}`

```txt
角色定义:
角色1=莫娜|水{技能3消耗=1水骰子+2任意,技能2消耗=3水骰子,技能1消耗=3水骰子}
角色2=砂糖|风{技能3消耗=1风骰子+2任意,技能2消耗=3风骰子,技能1消耗=3风骰子}
角色3=琴|风{技能3消耗=1风骰子+2任意,技能2消耗=3风骰子,技能1消耗=4风骰子}
```

| 部分        | 规则                                                         |
| ----------- | ------------------------------------------------------------ |
| `角色N`     | N 只能是 1、2、3                                             |
| `名字`      | 指令按这个名字匹配，不必是官方名                             |
| `元素`      | 只看第一个字：`水` / `火` / `冰` / `雷` / `风` / `岩` / `草` |
| `技能K消耗` | 费用写成 `3雷骰子`，普攻常见再加 `+2任意`                    |

甘雨这类四人技能可以写到技能4，例如：`角色3=甘雨|冰{技能4消耗=1冰骰子+2任意,技能3消耗=3冰骰子,技能2消耗=5冰骰子,技能1消耗=3冰骰子}`

#### 技能编号

和游戏里技能按钮一致：**从右往左数，从 1 开始**。

常见三人技能角色：

| 编号  | 通常对应           |
| ----- | ------------------ |
| 技能1 | 元素爆发（最右边） |
| 技能2 | 元素战技           |
| 技能3 | 普通攻击           |

甘雨这类四人技能：技能1 大招、技能2 霜华矢、技能3 战技、技能4 普攻。

#### 指令写法

每行只能这样写：

```txt
角色名 使用 技能N
```

不能写 `切换`、`出战`、`打出 xxx`。当前出战角色不是这条指令的角色时，会先切人（耗 1 个骰子）。切人算一次行动，之后再放技能。

第一条指令的角色，就是开局出战角色。

可选后缀：`骰子减少1` 或 `骰子增加1`（紧挨着写，中间不要空格）。一般用不着。它只改程序自己估算的消耗，用来判断「够不够进入下一步」；真正点技能、烧几张牌，仍按角色定义里的费用。

#### 程序实际会做什么

1. 开局出战 = 第一条指令的角色。
2. 放成功的技能会从列表里删掉。下回合接着做还没做完的指令，不会从文件第一行重来。
3. 当前出战角色不是这条指令的角色时，先切人（耗 1 个骰子）。切人算一次行动，之后再放技能。
4. 先看骰子**数量**够不够这条技能。数量不够，或已经没骰子 → **结束本回合**，下回合还从这条开始。**不会**改去尝试后面更便宜的技能。
5. 数量够、但缺对应元素 → 从左往右烧牌，把已有骰子**转成**需要的元素（不增加骰子数量，也不看牌名）。
6. 烧不成（例如手牌不够）→ 结束本回合，这条指令留到下回合再试。
7. 角色被打败，或身上有冻结等异常 → **跳过**该角色的指令，看后面的指令。
8. 列表里的指令全部做完 → 结束自动打牌。

因此内置示例常在后面再写一串不太可能用到的技能。这不是分支，只是角色死后或对局变长时的备用指令。

#### 做不到什么

- 按手牌内容分支（例如「有某某事件牌就打出」）
- 打出事件牌、装备牌、支援牌
- 指定烧哪一张手牌
- `if` / 按回合分段 / 多套策略切换
- 按对方阵容、血量、充能自动改打法（充能本身也没有完整判断）

程序不识别牌名，只粗算手里还有几张牌。想针对特定对局，请另存一个 txt，在 BetterGI 里改选策略；游戏内角色顺序也要和文件里的 `角色1/2/3` 一致。不要在同一个 txt 里写条件。
